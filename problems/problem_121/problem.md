# Problem

## Problem Description

Consider the model of the circuit described. Calculate the output voltage, \( v_{\mathrm{o}}(t) \), obtained in response to a constant input voltage, \( v(t) = \widetilde{v},\ t \geq 0 \). Identify the transient and the steady-state components of the response.

## Subproblems

1. Express the constant input voltage in the Laplace domain.
2. Write the transfer-function \( G(s) \) relating the input and output voltages.
3. Compute the Laplace transform of the output voltage \( V_o(s) \).
4. Perform partial fraction expansion of \( V_o(s) \).
5. Compute the inverse Laplace transform to obtain \( v_o(t) \).
6. Identify and interpret the transient and steady-state components of the response.

## Additional Information

- The system is assumed to be linear and time-invariant.
- Initial conditions are assumed to be zero.
- Circuit parameters \( R, C_1, C_2 \) are positive constants.
- Stability and response classification should follow standard LTI system theory.

## Constraints

- Laplace transform methods must be used.
- The response decomposition must be clearly justified.
- Mathematical steps should be explicitly shown.
- Final expressions should be simplified and physically interpretable.
