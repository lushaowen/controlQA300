# Problem

## Problem Description
For each block-diagram in Fig. 1.14, identify the system inputs, outputs, and other relevant internal signals. Describe what physical quantities these signals could represent in a real-world system.

Based on the presence or absence of feedback, determine whether each system operates in an open-loop or closed-loop configuration. Analyze whether the relationship between the inputs and outputs is static or dynamic.

For each block, write a simple mathematical relationship that could represent the behavior of the system. Identify which signals, if any, act as disturbances.
