# Solution

## Method

Let

\[
x = y + {k}^{-1}{mg}\sin \theta ,\;\dot{x} = \dot{y},\;\ddot{x} = \ddot{y}
\]

and substitute into the equation obtained in P2.28 to obtain

\[
m\ddot{y} + b\dot{y} + {ky} + {mg}\sin \theta  = {mg}\sin \theta
\]

or

\[
m\ddot{y} + b\dot{y} + {ky} = 0.
\]

This means that the constant force provided by gravity does not affect the dynamic behavior of this system. As expected it shifts the static equilibrium from \( {x}_{0} = {\ell }_{0} \) to \( {x}_{0} = {\ell }_{0} + {k}^{-1}{mg}\sin \theta \) .


## Teaching Points

1. Constant external forces shift equilibrium but do not alter system dynamics
2. Coordinate transformations can eliminate constant forcing terms
3. Homogeneous equations describe deviations from equilibrium
4. Dynamic behavior is governed by system parameters, not constant inputs
5. Equilibrium-based modeling simplifies analysis and control design
