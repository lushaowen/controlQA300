# Solution


## Method

When \( q, w,{T}_{o} \) , and \( {T}_{i} \) are constants the solution to the differential equation is

which has as solution

\[
T\left( t\right)  = \widetilde{T}\left( {1 - {e}^{\lambda t}}\right)  + T\left( 0\right) {e}^{\lambda t}
\]

where

\[
\lambda  =  - \frac{{Rwc} + 1}{Rmc},\;\widetilde{T} = \frac{{Rq} + {Rwc}{T}_{i} + {T}_{o}}{{Rwc} + 1}.
\]


## Teaching Points

1. Many thermal systems can be modeled as first-order ODEs.
2. Heat flow and mass flow jointly determine temperature dynamics.
3. The thermal resistance influences both transient speed and steady-state value.
4. The solution structure mirrors electrical and mechanical first-order systems.
5. Lumped-parameter models simplify analysis while capturing key behavior.
