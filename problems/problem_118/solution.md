# Solution

## Method
Assuming zero-initial conditions and applying the Laplace transform

from which

\[
{V}_{c}\left( s\right)  = G\left( s\right) V\left( s\right) ,\;G\left( s\right)  = \frac{\frac{1}{LC}}{{s}^{2} + \frac{R}{L}s + \frac{1}{LC}} = \frac{{\omega }_{n}^{2}}{{s}^{2} + {2\zeta }{\omega }_{n}s + {\omega }_{n}^{2}},\;{\omega }_{n} = \sqrt{\frac{1}{LC}},\;\zeta  = \frac{R\sqrt{C}}{2\sqrt{L}}.
\]
