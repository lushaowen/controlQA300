# Solution

## Method
Solving for the current

\[
{i}_{a} = \frac{1}{{R}_{a}}{v}_{a} - \frac{{K}_{e}}{{R}_{a}}\omega
\]

so that

\[
J\dot{\omega } + {b\omega } = \tau
\]

\[
= {K}_{t}{i}_{a}\text{ , }
\]

\[
= \frac{{K}_{t}}{{R}_{a}}{v}_{a} - \frac{{K}_{t}{K}_{e}}{{R}_{a}}\omega
\]

which is equal to the expression sought after rearranging.

## Teaching Points

1. Electrical dynamics can introduce effective mechanical damping
2. Back-EMF provides speed-dependent negative feedback
3. Neglecting inductance simplifies the model to first order
4. DC motors naturally exhibit electromechanical coupling
5. This form is commonly used in control-oriented motor models
