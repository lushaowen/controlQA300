# Problem

## Problem Description

Evaluate the product \( F\left( s\right) G\left( s\right) \) first as \( \mathcal{L}\{ f\left( t\right) \} G\left( s\right) \) then use the shift property to establish the convolution property in Table 3.2. Hint: Assume that \( f\left( t\right)  = g\left( t\right)  = 0 \) , for all \( t < 0 \) and that you can switch the order of integration.

![alt text](images\image.png)

## Subproblems

1. Express \( F(s)G(s) \) using the integral definition of the Laplace transform.
2. Interpret \( G(s) \) as the Laplace transform of a shifted function.
3. Convert the product into a double integral.
4. Justify changing the order of integration.
5. Identify the resulting expression as the Laplace transform of a convolution.
6. Simplify the integration limits using causality.

## Additional Information

- Assume all integrals converge.
- You may interchange the order of integration.
- Use the fact that \( g(t) = 0 \) for all \( t < 0 \).

## Constraints

- The proof must begin from the definition of the Laplace transform.
- No direct use of convolution tables.
- All steps must be explicitly justified.
