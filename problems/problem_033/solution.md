# Solution


## Method
Using Kirchoff's voltage and current law:

\[
v = {v}_{C} + {v}_{R}
\]

\[
= {v}_{C} + R{i}_{R}
\]

\[
= {v}_{C} + R{i}_{C}
\]

\[
= {v}_{C} + {RC}{\dot{v}}_{C}
\]

which is the desired differential equation.

## Teaching Points

1. Kirchhoff’s laws provide a direct path from circuit topology to differential equations
2. Capacitors introduce state variables through energy storage
3. Series circuits enforce identical currents through all elements
4. RC circuits are first-order dynamical systems
5. Electrical systems admit modeling techniques analogous to mechanical systems
