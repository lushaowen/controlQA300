# Solution

## Method
All \( \lambda \) and \( z \neq  0 \) such that \( \left( {{A}^{ * } - {\lambda I}}\right) z \) are given by

\[
\left\lbrack  \begin{matrix} \lambda & 0 \\   - 1 & \lambda  \end{matrix}\right\rbrack  \left( \begin{array}{l} {z}_{1} \\  {z}_{2} \end{array}\right)  = 0\; \Rightarrow  \;\lambda  = 0,\;\left( \begin{array}{l} {z}_{1} \\  {z}_{2} \end{array}\right)  = \left( \begin{array}{l} 0 \\  1 \end{array}\right)
\]

Therefore

\[
0 = {B}^{ * }z = \left\lbrack  \begin{array}{ll} 1 & \beta  \end{array}\right\rbrack  \left( \begin{array}{l} 0 \\  1 \end{array}\right)  = \beta
\]

only when \( \beta  = 0 \) .

2. Interpretation of uncontrollability via adjoint eigenvectors

4. Connection between algebraic conditions and system structure
