# Solution

## Method

a) \( G(s) = \dfrac{s+1}{s+10} \)

b) \( G(s) = \dfrac{s+10}{s+1} \)

c) \( G(s) = \dfrac{10}{(s+1)(s+10)} \)

d) \( G(s) = \dfrac{s+10}{(s+1)^2} \)

e) \( G(s) = \dfrac{100}{(s+1)(s+10)^2} \)

f) \( G(s) = \dfrac{10}{s(s+10)} \)

g) \( G(s) = \dfrac{10s}{s+10} \)

h) \( G(s) = \dfrac{s+10}{s^2 + 0.15s + 1} \)

i) \( G(s) = \dfrac{s+10}{s^3 + 0.15s^2 + s} \)

j) \( G(s) = \dfrac{10}{(s^2 + 1)(s+10)} \)

k) \( G(s) = \dfrac{100}{(s^2 + 0.2s + 1.01)(s^2 + 0.2s + 100)} \)

l) \( G(s) = \dfrac{100s}{(s^2 + 0.2s + 1.01)(s^2 + 0.2s + 100)} \)

m) \( G(s) = \dfrac{100s^2}{(s^2 + 0.2s + 1.01)(s^2 + 0.2s + 100)} \)

n) \( G(s) = \dfrac{s^2 + 0.2s + 1.01}{s(s^2 + 0.2s + 100)} \)

o) \( G(s) = \dfrac{s^2 + 0.2s + 100}{s^2 + 0.2s + 1.01} \)

p) \( G(s) = \dfrac{s^2 + 0.2s + 100}{s^2 + 0.2s + 1.01} \) （same as o）

## Teaching Points

1. Identification of poles and zeros from Bode magnitude slopes
2. Use of straight-line asymptotic approximations in frequency-domain analysis
3. Relationship between slope changes and system order
4. Recognition of integrators and differentiators from low-frequency behavior
5. Identification of complex-conjugate poles from second-order roll-off patterns
6. Importance of minimum-phase assumptions when phase data is unavailable
7. Construction of rational transfer functions from frequency-domain data
