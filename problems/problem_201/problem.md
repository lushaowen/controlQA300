# Problem

## Problem Description

Use the root-locus method to determine a proper feedback controller that can stabilize the SISO systems with poles and zeros shown in Fig. 6.25. Is the transfer-function of the controller asymptotically stable? Recall that you should never perform a pole-zero cancellation on the right-hand side of the complex plane. Note: Some are not trivial!

## Subproblems

1. Identify the unstable poles and zeros of each SISO system shown in Fig. 6.25.
2. Determine whether static gain feedback is sufficient to stabilize each system.
3. If static gain is insufficient, propose a dynamic controller using additional poles or zeros.
4. Use root-locus rules to justify how the proposed controller stabilizes the closed-loop system.
5. Check whether the controller itself is asymptotically stable.
6. Verify that no pole-zero cancellation occurs in the right-half complex plane.

## Additional Information

- All systems are single-input single-output (SISO).
- Controller design is restricted to proper transfer functions.
- Right-half-plane pole-zero cancellation is forbidden.
- Root-locus techniques should be used as the primary design tool.

## Constraints

- The controller must render the closed-loop system asymptotically stable.
- The controller transfer function must be proper.
- Pole-zero cancellations in the right-half plane are not allowed.
- Solutions may not be unique; justification is required.
