# Problem

## Problem Description

Verify that

\[
\overline{\theta } = 0,\;\overline{\omega } = \left( {{\overline{\omega }}_{1},{\overline{\omega }}_{2},{\overline{\omega }}_{3}}\right)  = \left( {\Omega ,0,0}\right)
\]

is an equilibrium point for the rigid body  Linearize the equations about this equilibrium point and show that if \( {J}_{2} < {J}_{1} < {J}_{3} \) or \( {J}_{3} < {J}_{1} < {J}_{2} \) then this is an unstable equilibrium point. Interpret this result.

## Subproblems

1. Verify that the given angular velocity corresponds to an equilibrium solution of the rigid-body equations.
2. Compute the Jacobian matrix of the nonlinear dynamics at the equilibrium point.
3. Derive the linearized state-space model around the equilibrium.
4. Compute the eigenvalues of the linearized system matrix.
5. Determine stability conditions in terms of the principal moments of inertia.
6. Analyze how the ordering of inertia values affects stability.
7. Provide a physical interpretation of the instability result.

## Additional Information

- The rigid body is assumed to be torque-free at equilibrium.
- The dynamics follow Euler’s equations for rigid body rotation.
- Linearization is performed about a constant angular velocity solution.
- Stability is assessed using eigenvalue analysis of the linearized model.
- Moments of inertia satisfy \( J_i > 0 \).

## Constraints

- Linearization must be carried out analytically.
- Stability conclusions must follow directly from eigenvalue signs.
- Physical interpretation should be consistent with rigid body dynamics.
- Assumptions must be clearly stated.
