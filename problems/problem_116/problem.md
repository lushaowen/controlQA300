# Problem

## Problem Description
Consider the model of the circuit described. Calculate the capacitor voltage, \( {v}_{C}\left( t\right) \), obtained in response to a constant input voltage, \( v\left( t\right)  = \widetilde{v}, t \geq  0 \). Identify the transient and the steady-state components of the response.

## Subproblems
1. Express the constant input voltage in the Laplace domain.
2. Write down the transfer function of the circuit as given in P3.80.
3. Compute the Laplace transform of the capacitor voltage.
4. Perform partial fraction expansion to simplify the expression.
5. Determine the time-domain response using inverse Laplace transform.
6. Identify and classify the transient and steady-state components of the response.

## Additional Information
- The circuit is modeled as a first-order linear time-invariant system.
- Zero initial conditions are assumed.
- A constant input corresponds to a step input in the Laplace domain.
- The parameters \( \alpha \) and \( \beta \) are defined by the circuit resistance and capacitance.

## Constraints
- All circuit parameters are positive.
- Laplace transform methods must be used for the analysis.
- The response should be expressed explicitly as a function of time.
- Transient and steady-state terms must be clearly distinguished.
