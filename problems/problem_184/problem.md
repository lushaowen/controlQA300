# Problem

## Problem Description
Verify that the linearized model of a satellite in  controllable if tangential thrust alone is used. Interpret this result on the basis of your knowledge of the system. 

## Subproblems
1. Write the linearized state-space equations when only tangential thrust is applied.
2. Identify the system matrix \( A \) and the input matrix \( B \) for tangential control.
3. Determine the eigenvalues of the system matrix and their physical significance.
4. Examine the left-eigenvectors associated with the system eigenvalues.
5. Apply the controllability condition from P5.3 to verify full controllability.
6. Interpret why tangential thrust is sufficient to control all system states.

## Additional Information
- The satellite motion is linearized about a nominal circular orbit.
- The angular rate \( \Omega \) is assumed constant.
- Only tangential thrust \( u_t \) is available as the control input.
- Use standard controllability results for linear time-invariant systems.
- Reference P5.3 for eigenvalue-based controllability analysis.

## Constraints
- Mathematical verification must be clearly shown.
- Physical interpretation should be consistent with orbital mechanics.
- Assume ideal actuators with no saturation or delays.
- Ignore nonlinear and disturbance effects.
