# Problem: Sensitivity Function of a Closed-Loop System

## Problem Description
Show that the sensitivity function defined in equation (1.3) is the one associated with the closed-loop transfer function
$$
H(G) = \frac{GK}{1 + GK}.
$$

Use the definition of the sensitivity function and analytical differentiation to derive the result.

\[H(G) = \frac{GK}{1 + GK}, \quad \implies \quad S(G) = \frac{1}{1 + GK}. \tag{1.3}\]
## Subproblems
1. Recall the definition of the sensitivity function with respect to $G$.
2. Compute the derivative of the closed-loop transfer function $H(G)$ with respect to $G$.
3. Substitute the result into the sensitivity definition.
4. Simplify the expression and interpret the result.

## Additional Information
- Assume $K$ is a constant gain.
- All functions are scalar and differentiable.
- Use standard calculus rules.

## Constraints
- All derivation steps must be shown.
- Algebraic simplifications should be explicit.
- Final result should be expressed in simplest form.
