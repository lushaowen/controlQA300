# Solution



## Method
Using the definition of the sensitivity function.

\[
S\left( G\right)  = \frac{G}{H\left( G\right) }{H}^{\prime }\left( G\right)
\]

when \( H\left( G\right)  = {\left( 1 + GK\right) }^{-1}{GK} \)

\[
{H}^{\prime }\left( G\right)  = \frac{K}{1 + {GK}} - \frac{G{K}^{2}}{{\left( 1 + GK\right) }^{2}} = \frac{K}{{\left( 1 + GK\right) }^{2}}
\]

with which

\[
S\left( G\right)  = \frac{G}{H\left( G\right) }{H}^{\prime }\left( G\right)  = \frac{G\left( {1 + {KG}}\right) }{GK}\frac{K}{{\left( 1 + GK\right) }^{2}} = \frac{1}{1 + {GK}}.
\]

## Teaching Points
1. Sensitivity quantifies how parameter variations affect system behavior
2. Closed-loop systems reduce sensitivity through feedback
3. Differentiation of transfer functions is a key analytical tool
4. Algebraic simplification reveals physical insight
