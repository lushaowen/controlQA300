# Problem

## Problem Description
Verify that the linearized model of a satellite in is not controllable if only radial thrust is used. Interpret this result on the basis of your knowledge of the system. 

## Subproblems
1. Write down the linearized state-space model of the satellite when only radial thrust is applied.
2. Identify the system matrix \( A \) and input matrix \( B \) corresponding to radial thrust.
3. Analyze the controllability of the system using standard linear systems theory.
4. Determine whether all state variables can be influenced by the radial control input.
5. Provide a physical interpretation of why the system is or is not controllable with only radial thrust.

## Additional Information
- The satellite dynamics are linearized about a nominal circular orbit.
- The angular velocity \( \Omega \) is assumed constant.
- Only one control input (radial thrust) is available.
- Reference Problem P5.3 for controllability concepts and criteria.

## Constraints
- Use linear system controllability concepts.
- Mathematical justification must accompany qualitative reasoning.
- Physical interpretation should be consistent with orbital mechanics principles.
- Assume idealized conditions with no disturbances or nonlinear effects.
