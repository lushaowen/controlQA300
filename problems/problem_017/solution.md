## Method

In order to achieve a desired rotational speed \( {\overline{\omega }}_{2} = 4\mathrm{{rad}}/\mathrm{s} \) in steady-state we set a desired rotational speed \( {\overline{\omega }}_{1} = \left( {{r}_{2}/{r}_{1}}\right) {\overline{\omega }}_{2} \) and calculate

\[
\tau  = \overline{\tau } = \frac{{b}_{1}{r}_{2}^{2} + {b}_{2}{r}_{1}^{2}}{{r}_{2}^{2}}{\overline{\omega }}_{1}.
\]

Substituting the data we obtain

\[
{\overline{\omega }}_{1} = \left( {{r}_{2}/{r}_{1}}\right) {\overline{\omega }}_{2} = {80}\mathrm{{rad}}/\mathrm{s},\;\overline{\tau } = \frac{{b}_{1}{r}_{2}^{2} + {b}_{2}{r}_{1}^{2}}{{r}_{2}^{2}}{\overline{\omega }}_{1} \approx  {0.82}\mathrm{\;N}\mathrm{\;m}.
\]

## Teaching Points
1. Steady-state speed in open-loop systems is set by torque–damping balance.
2. Belt-driven systems scale angular velocities via pulley radii.
3. Inertia affects transient behavior, not steady-state speed.
4. Open-loop control is sensitive to parameter uncertainty.
5. This problem motivates the need for feedback control.
