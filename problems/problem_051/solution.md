# Solution

## Method

if \( q = {12}\mathrm{\;{kW}} \) and \( w = 0 \)

\[
{mc}\dot{T} + \frac{1}{R}T = q + \frac{1}{R}{T}_{o}.
\]

which has as solution

\[
T\left( t\right)  = \widetilde{T}\left( {1 - {e}^{\lambda t}}\right)  + T\left( 0\right) {e}^{\lambda t}
\]

where

\[
\lambda  =  - \frac{1}{Rmc} \approx   - {4.73} \times  {10}^{-6}{\mathrm{\;s}}^{-1}
\]

and

\[
\widetilde{T} = {T}_{o} + {Rq} \approx  {3222}^{ \circ  }\mathrm{C}.
\]

If \( T\left( 0\right)  = {25}^{ \circ  }\mathrm{C} \) and \( T\left( t\right)  = {60}^{ \circ  }\mathrm{C} \) then

\[
t = \frac{1}{\lambda }\log \frac{T\left( t\right)  - \widetilde{T}}{T\left( 0\right)  - \widetilde{T}} \approx  {2326}\mathrm{\;s}
\]

or about 39 minutes.


## Teaching Points

1. Heating and cooling dynamics share the same system time constant.
2. Constant power input shifts the equilibrium temperature without changing stability.
3. Large equilibrium temperatures highlight modeling assumptions and limitations.
4. Time-to-temperature depends logarithmically on the temperature ratio.
