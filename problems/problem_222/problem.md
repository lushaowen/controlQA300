# Problem

## Problem Description

Use the Nyquist stability criterion to decide whether the rational transfer-functions in  are stable under negative unit feedback. If not, is there a gain for which the closed-loop system can be made asymptotically stable? Draw the corresponding root-locus diagrams and compare them.

(a) \( G = \frac{1}{\left( {s + 1}\right) \left( {s + {10}}\right) } \) ; (e) \( G = \frac{s + {10}}{{s}^{2} - {0.1s} + 1} \) ; (i) \( G = \frac{s + 1}{{s}^{2}\left( {s + {10}}\right) } \) ;

(b) \( G = \frac{s + {0.1}}{\left( {s + 1}\right) \left( {s + {10}}\right) } \) ; (f) \( G = \frac{s}{\left( {s + 1}\right) \left( {s + {10}}\right) } \) ; (j) \( G = \frac{s + {10}}{{\left( {s}^{2} + {0.1}s + 1\right) }^{2}} \) .

(c) \( G = \frac{s + {10}}{{s}^{2} + {0.1s} + 1} \) (g) \( G = \frac{s + {10}}{{\left( s + 1\right) }^{2}} \) (k) \( G = \frac{s + 1}{{s}^{2}{\left( s + {10}\right) }^{2}} \)

(d) \( G = \frac{s - {0.1}}{\left( {s - 1}\right) \left( {s + {10}}\right) } \) ; (h) \( G = \frac{s + 1}{s\left( {s + {10}}\right) } \) ; (l) \( G = \frac{{\left( s + 1\right) }^{2}}{s\left( {s + {10}}\right) } \)

## Subproblems

1. For each given transfer function (a–k), identify the open-loop poles and zeros.
2. Determine the number and direction of Nyquist encirclements of the critical point \(-1 + j0\).
3. Decide whether the closed-loop system is stable under negative unit feedback.
4. If unstable, determine whether there exists a gain \( K \) such that the system becomes asymptotically stable.
5. Identify the admissible range of gain values \( K \) that ensure stability, if applicable.
6. Sketch or interpret the corresponding root-locus diagrams for each case.
7. Compare the stability conclusions obtained from the Nyquist criterion with those suggested by the root-locus method.

## Additional Information

- Assume all systems are linear time-invariant (LTI) and described by rational transfer functions.
- Negative unit feedback is applied in all cases.
- Nyquist plots are evaluated with respect to the open-loop transfer function \( L(s) = K G(s) \).
- Root-locus diagrams correspond to variations of the real scalar gain \( K \ge 0 \).
- Stability refers to asymptotic stability of the closed-loop system.

## Constraints

- Stability conclusions must be justified using the Nyquist stability criterion.
- The number of right-half-plane poles must be accounted for explicitly.
- Gain ranges should be stated clearly where stabilization is possible.
- Qualitative comparison with root-locus results is required.
- Standard control theory terminology must be used.
