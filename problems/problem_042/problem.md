# Problem: Parameter Estimation of a DC Motor Using Stall Torque

## Problem Description

A DC motor is supplied with a constant armature voltage \( v_a = 12\;\mathrm{V} \).
The armature resistance is known to_toggle to be \( R_a = 0.2\;\Omega \).
When the motor shaft is mechanically locked (stall condition), the measured stall torque is
\[
\tau = 1.2\;\mathrm{N\,m}.
\]

Using this information, estimate the following DC motor parameters:

- Rotor inertia \( J \)
- Torque constant \( K_t \)
- Back-emf constant \( K_e \)
- Viscous friction coefficient \( b \)

The stall torque is attained when the motor is held in place, meaning the angular velocity is zero.

---

## Subproblems

1. Explain the electrical and mechanical conditions that occur at stall.
2. Derive an expression for the torque constant \( K_t \) using the stall torque.
3. Determine the back-emf constant \( K_e \).
4. Estimate the rotor inertia \( J \) using known system parameters.
5. Compute the viscous friction coefficient \( b \).
6. Interpret the physical significance of the obtained parameter values.

---
