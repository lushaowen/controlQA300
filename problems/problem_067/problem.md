# Problem: Unit Area Property of the Dirac Delta Function

## Problem Description

Use the result  together with representation (3.7) of the Dirac delta function to show that the delta function has unit area, namely,

$$
\int_{-\infty}^{\infty} \delta(t)\, dt = 1.
$$

This problem provides a rigorous justification of a fundamental property of the Dirac delta function using limits and improper integrals.

---

## Subproblems

1. Recall the representation of the Dirac delta function given in equation (3.7).
2. Express the integral of \( \delta(t) \) over the real line using this representation.
3. Interchange the order of limits and integration where appropriate.
4. Use the result of Problem 3.10 to evaluate the resulting integral.
5. Conclude that the total area under \( \delta(t) \) is equal to one.

---

## Additional Information

- You may assume that limits and integrals can be interchanged.
- The representation (3.7) of the delta function is
  \[
  \delta(t) = \lim_{\rho \to \infty} \frac{\sin(\rho t)}{\pi t}.
  \]
- The function \( \sin(\rho t)/t \) is an even function of \( t \).

---

## Constraints

- All steps must be shown clearly.
- Limits must be handled explicitly.
- The argument should rely on previously established results, not distribution theory.
