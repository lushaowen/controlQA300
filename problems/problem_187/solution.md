# Solution

## Method
Substitute:

\[
\frac{-b{\bar{x}}_{2}}{\left( {s + a}\right) \left( {s + c + {\bar{x}}_{1}}\right) } = \frac{-{3.3}{a}^{2}}{{\left( s + a\right) }^{2}} = \frac{-{3.3}}{{\left( 1 + {33}s\right) }^{2}}
\]

which has a double real pole at \( s =  - 1/{33} \) and no zeros.

The corresponding equilibrium point is asymptotically stable since the poles at \( s =  - 1/{33} \) have negative real part.
