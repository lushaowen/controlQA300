# Solution

## Method
Using Kirchoff's voltage and current law:

\[
v = {v}_{C} + {v}_{R} + {v}_{L}
\]

\[
= {v}_{C} + R{i}_{R} + L{\dot{i}}_{L}
\]

\[
= {v}_{C} + R{i}_{C} + L{\dot{i}}_{C}
\]

\[
= {v}_{C} + {RC}{\dot{v}}_{C} + {LC}{\ddot{v}}_{C},
\]

which is the desired equation.

## Teaching Points

1. The system dynamics are described by a **second-order linear differential equation**.
2. The inductance introduces the second derivative term.
3. This equation generalizes the RC circuit equation by adding energy storage in the inductor.
4. Depending on parameter values, the circuit may exhibit overdamped, underdamped, or critically damped behavior.
