# Solution

## Method
Calculate

\[
\mathcal{L}\left\{  {{\int }_{{0}^{ - }}^{t}f\left( \tau \right) \delta \left( {t - \tau }\right) {d\tau }}\right\}   = F\left( s\right)  \times  1 = F\left( s\right)  = \mathcal{L}\{ f\left( t\right) \} .
\]
## Teaching Points

1. Convolution with the Dirac delta leaves a signal unchanged
2. The delta function acts as an identity element under convolution
3. Laplace transform properties provide a rigorous proof of impulse behavior
4. The sifting property explains how impulses sample signals at precise instants
5. The lower limit $0^-$ ensures correct handling of impulsive components
